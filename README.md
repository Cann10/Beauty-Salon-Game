# Beauty-Salon-Game

DxLibで制作した美容室経営シミュレーションゲームです。

## Overview

プレイヤーは美容室のオーナーとなり、
スタッフ育成や設備拡張を行いながら
人気店を目指します。

## Features

- 美容室経営システム
- スタッフ育成
- スタッフ会話システム
- CUT席 / SHAMPOO席拡張
- 観葉植物・内装変更
- スタッフ雇用
- タイトル画面
- 美容室名入力

## Controls

| Key | Action |
|---|---|
| TAB | メニュー表示 |
| C | CUT席追加 |
| S | SHAMPOO席追加 |
| P | 観葉植物追加 |
| T | 内装変更 |
| 1〜3 | スタッフ強化 |
| A | アオイ雇用 |
| ENTER | 決定 |

## Development Environment

- C++
- DxLib
- Visual Studio 2022
