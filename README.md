# Beauty-Salon-Game

DxLibで制作した美容室経営シミュレーションゲームです。
プレイヤーは美容室のオーナーとなり、スタッフ育成や設備拡張を行いながら人気店を目指します。

---

# Gameplay

プレイヤーは美容室を経営し、
スタッフ育成や設備拡張を行いながら人気店を目指します。

- スタッフ雇用
- CUT席追加
- シャンプー席追加
- 人気度システム
- 顧客対応

# 制作理由

カイロソフト作品が好きで、
「小さなお店を少しずつ育てていく楽しさ」を自分でも作ってみたいと思い制作しました。

また、ゲーム制作を通してC++や設計力を学ぶことも目的としています。

# プレイ方法

## ダウンロード方法

Releases から zip ファイルをダウンロードしてください。

## 起動方法

Release フォルダ内の
`Beauty salon.exe`
を実行してください。

※ Windows環境で動作確認済み

---


## ビルド方法

1. Visual Studioでプロジェクトを開く
2. DxLibを導入
3. 実行
